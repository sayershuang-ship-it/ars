# ep002 — 北港朝天宮迎媽祖：炮場感官體驗

## Topic

- Audience      廟會文化愛好者、台灣在地文化一般觀眾（per SERIES_GUIDE）
- Thesis        跟著一組轎班走過一個炮場——用煙、聲、火光、熱浪與人群反應，讓觀眾感受站在炮場旁邊是什麼樣子
- CTA           軟性 — 結尾字幕帶訂閱按讚，旁白一句：「下次農曆三月十九，來北港站看看」
- Hero visual   炮陣炸開瞬間：乳白色濃煙吞沒畫面，紅色炮紙與熱氣一起翻騰，視線內只剩人影輪廓
- Source        Web 報導畫面（yahoo/中央社/創新聞等報導中的現場照片與影片截圖）；無專屬 footage
- Target length 5–6 分鐘，8 個 review sections
- Constraints   炮場體驗描述以可查證的報導與第一人稱帳為準；「愈炸愈旺」等民俗含義保留但不誇大

## Reminders

- **本期無實拍 footage** — 所有「實拍畫面」需從 Web 報導照片/影片截圖取得，或由 build 階段搜尋可使用的 CC/新聞畫面。Open 時先確認可用圖源數量是否足夠支撐 8 個 section。
- **Hero 是畫面不是卡片** — cover 和一組連續 image cards 就是視覺主力。不要用 markdown 卡片塞文字替代實拍。
- **炸轎 vs 犁炮的節奏差異是本期核心** — 炸轎是瞬間一次爆發（煙霧衝出→轎班身影消失→再出現），犁炮是連續快速掃射（光弧→炮雨→持續撞擊聲）。這兩個 section 的剪接節奏不一樣，build 時需要在 image 卡的切換速度上做出區別。
- **Section 6「站在炮場旁邊」是純感官段落** — 沒有新的事件發生，而是停下來描述「站在那裡的感受」。旁白可引用 VERSE 的「固化的乳白」、「連視野也被吞沒」，但要搭配畫面（炮灰、煙霧、人群表情）而非純文字。
- **藝閣段落的視覺反差是關鍵** — 從炮陣的灰白煙霧進到藝閣的彩色熱鬧，是本期唯一的節奏轉換點。畫面飽和度要明顯不同。
- **炮聲定義了本期 tone** — 每段炮聲的音效設計比旁白更重要（尤其 Opening 第一秒）。確認 Remotion 支援多音軌或能疊環境音效。
- **綠色通道（大同路）可作為 trivia** — 可放在 Section 2 的一句旁白補充，不必獨立成一段。
- **犁炮手技術畫面** — 報導中有「犁頭搭配火爐燒紅」的描述，但具體圖片素材需確認是否存在。若無合適圖源，Section 5 可改用文字 overlay 搭配示意圖。
